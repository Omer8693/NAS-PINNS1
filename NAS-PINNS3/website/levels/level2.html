Level 2

Temporal Skip Operator

Instead of running FEM at every time step, the PINN learns to map the current temperature field Tk directly to Tk+s, skipping s−1 FEM solves. FEM runs only at anchor points; PINN fills all intermediate steps.

Skip factor s = 1, 2, 4, 8 Convergence: ratio < 1.5× 500 ep · 2000 ep comparison
Concept

How the Skip Operator Works

FEM solves the heat equation step by step. Each FEM call is expensive. With skip=s, only every s-th step uses FEM; the PINN predicts the intermediate steps in milliseconds.

Without skip (s=1)

FEM t₀ → FEM t₁ → FEM t₂ → FEM t₃ → ···

With skip=2

FEM t₀ → PINN t₁ → FEM t₂ → PINN t₃ → ···

With skip=4

FEM t₀ → PINN t₁ → PINN t₂ → PINN t₃ → FEM t₄ → ···

PINN Input / Output

Input: Tk(x, y) — current field
Output: Tk+s(x, y) — field s steps ahead

Convergence Criterion

MAE(skip=s) / MAE(skip=1) < 1.5× → CONVERGED ✓

A ratio above 1.5× means the skip-induced error is too large compared to the baseline (no-skip) error.

FEM Call Reduction

Reduction = 1 − 1/s
skip=2 → 50% fewer FEM calls
skip=4 → 75% fewer FEM calls

Results — 2000 Epochs

Skip Operator Results (2000 Epochs)

With more training epochs, even the smaller NSGA-II and NSGA-III architectures converge at skip=2 — confirming that epoch count was the main bottleneck.

Takeaways

Key Observations

  • ✓
    Bayesian architecture converges up to skip=4 5×151 relu (93k params) achieves ratio=1.32× at skip=4 → 75% fewer FEM calls with no convergence failure.
  • ✓
    NSGA-II skip=2 converges at 500 epochs Ratio = 1.47× < 1.5× threshold → converged. Often misreported as failing — the margin is tight but valid.
  • ✓
    2000 epochs: all optimisers converge at skip=2 NSGA-II ratio=0.98×, NSGA-III ratio=0.99× — epoch count was the bottleneck, not architecture capacity.
  • →
    Skip=8 fails for all architectures at 500 epochs Predicting 8 steps ahead is too large a jump; the PINN cannot generalise that far without much more training data and epochs.
