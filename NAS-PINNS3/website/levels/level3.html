Level 3

Hybrid FEM + PINN Routing

At each time step, the PDE residual of the current PINN prediction is evaluated. If the residual is large (r > threshold), FEM is called for accuracy. Otherwise the PINN prediction is accepted — automatically reducing FEM usage by 80–95%.

Residual-based routing Threshold = 0.1 80–95% FEM step reduction
Concept

Adaptive Routing Algorithm

Unlike Level 2 (fixed skip pattern), Level 3 decides dynamically at each step whether to use FEM or PINN. The decision is based on the PDE residual — a measure of how well the PINN currently satisfies the heat equation.

Routing Logic

r = ||ρCₚ ∂T/∂t − K∇²T|| / ||ρCₚ ∂T/∂t||

if r > threshold → use FEM
else → accept PINN prediction

The residual is computed using automatic differentiation on the PINN output. It captures when the PINN is drifting from the true physics.

Expected Benefits

  • No manual skip factor tuning needed

  • Compatible with any PINN architecture from Level 1

Takeaways

Key Observations

  • ✓
    80–90% FEM step reduction achieved automatically No manual skip factor needed. The residual threshold handles all routing decisions adaptively.
  • ✓
    FEM is called exactly when needed The four FEM triggers in Config A correspond to the early rapid cooling phase — exactly when the physics changes fastest.
  • →
    Larger max-skip allows greater reduction Config B (max skip=20) achieves 90% reduction but relies more heavily on the PINN over long intervals.
  • →
    Threshold tuning is the key design decision Threshold=0.1 provides a good balance. Lower threshold → more FEM calls (safer). Higher → more PINN usage (faster, riskier).
