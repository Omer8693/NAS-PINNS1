Level 3 of 7
Hybrid FEM + PINN Routing

At each time step, the PDE residual of the current PINN prediction is evaluated. If the residual exceeds a threshold (r > 0.1), FEM is called for accuracy. Otherwise the PINN prediction is accepted — automatically reducing FEM usage by 81–90% with no manual skip-factor tuning.

Residual-based routing Threshold = 0.1 81–90% FEM step reduction
Concept

Adaptive Routing Algorithm

Unlike Level 2 (fixed skip pattern), Level 3 decides dynamically at each step whether to use FEM or PINN. The decision is based on the PDE residual — a measure of how well the PINN currently satisfies the heat equation.

Routing Logic

r = ||ρCₙ ∂T/∂t − K∇²T|| / ||ρCₙ ∂T/∂t||

if r > threshold → use FEM (expensive, accurate)
else → accept PINN prediction (fast)

The residual is computed using automatic differentiation on the PINN output, capturing when the PINN is drifting from the true physics.

Expected Benefits
  • No manual skip factor tuning required
  • FEM called automatically when physics diverges
  • Works for non-uniform quenching (variable cooling rates)
  • Compatible with any PINN architecture from Level 1

The residual formula r = ||ρCₙ ∂T/∂t − K∇²T|| / ||ρCₙ ∂T/∂t|| quantifies how strongly the PINN output violates the heat equation at the current time step. A large residual indicates the PINN is extrapolating into a region of parameter space where it was not accurately trained. Setting the threshold at 0.1 means we accept PINN predictions when the PDE violation is less than 10% of the transient driving term. This is a physics-informed quality gate that replaces the fixed, manually-chosen skip factor of Level 2 with an adaptive, solution-driven rule.

The routing overhead (computing the PDE residual at each step) is negligible compared to a FEM solve. The residual computation uses auto-differentiation through the already-trained PINN, which takes milliseconds. The max-skip parameter caps how many consecutive PINN steps are allowed even if the residual stays below threshold — Config A's cap of 4 is conservative, while Config B's cap of 20 allows long PINN-only runs when the physics is smooth.

Config A reduces FEM calls from 21 to just 4 — an 81% reduction — with the router making all decisions automatically. The four FEM triggers correspond to the early rapid-cooling phase (t < 5 s) where the thermal gradient is steepest and the PINN prediction uncertainty is highest. Config B's higher max-skip (20) allows the router to defer FEM even longer, reducing to just 2 FEM calls (90% reduction). The trade-off is greater reliance on the PINN over long intervals without an anchor-point correction.

Visualisations

Result Plots

FEM vs PINN Step Rates — Config A vs B

This bar chart compares FEM and PINN step counts for both configurations at threshold=0.1. Config A (max skip=4) uses 4 FEM calls and 17 PINN steps, while Config B (max skip=20) achieves 2 FEM and 19 PINN steps. The key insight is that both configurations automatically concentrate the few FEM calls in the high-residual region (early quench phase) while using PINN for the slower, more predictable later cooling. This adaptive behaviour would be difficult to achieve with fixed-skip approaches without prior knowledge of the solution dynamics.

Residual Trace — Config A

The residual trace plot shows the actual PDE residual value at each time step during the Level 3 simulation. Steps where the bar exceeds the dashed threshold line (0.1) are coloured to indicate a FEM trigger. The residual peaks sharply in the first two or three steps then decays rapidly as the casting temperature gradient moderates. This exponential decay pattern mirrors the analytical cooling curve T(t)=20+520·exp(−1.75×10³t) and confirms that the routing decision correctly prioritises FEM effort in the physically hardest region of the time domain.

Step Distribution — Config A

This visualisation shows all 21 time steps coloured by solver choice for Config A. The pattern clearly shows FEM clustering at the early steps and PINN dominating the middle and late simulation time. The clustering is not periodic (unlike Level 2's fixed-skip pattern) but is physics-driven: FEM is called exactly when the residual tells the router that the PINN is struggling, then released again as the solution smooths out.

Step Distribution — Config B

Config B's step distribution shows even fewer FEM calls — just 2 in the entire 21-step run. With max-skip raised to 20, the router can allow up to 20 consecutive PINN steps before forcing a FEM anchor. Since the residual quickly drops below 0.1 after the initial transient, the router exploits this and runs the PINN almost exclusively after the first couple of steps. The accuracy trade-off of this extreme reduction should be evaluated against the specific application's tolerance for PINN extrapolation error.
