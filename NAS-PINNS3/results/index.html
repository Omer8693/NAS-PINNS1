Framework

Seven-Level Progressive Pipeline

Each level builds on the previous. Levels 1–4 establish the core simulation pipeline. Levels 5–7 extend and validate across training regimes, PDE families, and geometries.

L1

Single-Shot NAS-PINN

Global T(t,x,y) predictor. NAS searches layers, neurons, activation. Bayesian finds 5×151 relu.

Bayesian L2 = 0.076 ✓
L2

Temporal Skip Operator

PINN learns T_prev → T_next. FEM only at anchor steps. skip=2 → 2× fewer FEM solves.

skip=4 still converges
L3

Hybrid FEM + PINN

PDE residual decides routing. r > 0.1 → FEM, else → PINN. 80–95% skip rate.

80% FEM step reduction
L4

Distortion Mechanics

PINN T-field → plane-stress FEM → CMM distortion. Compared to paper Fig 17/18.

Bayesian δ̄ = 1.67 mm
L5

Extended Training

Longer Adam with cosine LR. NSGA-II: 4.5× improvement, L2 0.252 → 0.055.

NSGA-II meets target ✓
L6

Poisson Fine-Tuning

Auxiliary Poisson loss added to quenching network. Marginal regularisation benefit (+17%).

Bayesian L2 → 0.031
L7

Multi-Domain NAS

Poisson NAS across 5 geometries: Square, Circle, Annulus, L-Shape, Flower.

Circle L2 = 0.00014 ✓

Summary

Key Findings

  • ✓
    PINN replaces FEM steps without accuracy loss Bayesian skip=2: MAE 33.2°C vs 43.6°C baseline — 2× fewer FEM calls, better result.
  • ✓
    Architecture size determines skip capability Bayesian 5×151 relu (93k params) converges at skip=4. NSGA-III 3×75 (12k params) fails at skip=2 with 500 epochs.
  • ✓
    Extended training closes the accuracy gap NSGA-II: L2 0.252 → 0.055 (4.5× improvement) with longer cosine LR — now meets target.
  • ✓
    Hybrid FEM+PINN: 80–95% step reduction Residual-based routing (threshold=0.1) automatically calls FEM only when needed.
  • ✓
    Epoch count was the bottleneck, not architecture 2 000 epochs: NSGA-II ratio=0.98× ✓ and NSGA-III ratio=0.99× ✓ — both converge at skip=2.
  • ✓
    NAS generalises across PDE families and geometries Circle: L2=0.00014 · L-Shape: L2=0.028 · 4 geometries successfully solved.
